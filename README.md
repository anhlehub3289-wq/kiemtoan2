# 🛡️ Hệ Thống Phát Hiện Giao Dịch Bất Thường - Streamlit App

Giải pháp sử dụng mô hình học máy không giám sát **Isolation Forest** để phát hiện rủi ro và gắn cờ các giao dịch tài chính bất thường.

## 📁 Cấu trúc thư mục tối giản
- `app.py`: File mã nguồn chính chứa giao diện ứng dụng và thuật toán.
- `requirements.txt`: Danh sách các thư viện Python cần cài đặt.
- `transactions_Q1_demo.csv`: Tệp dữ liệu giao dịch mẫu (bỏ chung vào thư mục này).
